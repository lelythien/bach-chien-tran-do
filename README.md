# 🏯 Bách Chiến Trận Đồ — Website

Landing page cho boardgame chiến thuật lịch sử Việt Nam **Bách Chiến Trận Đồ**.

## 🛠 Công nghệ

- **Next.js 14** — App Router
- **TailwindCSS** — Styling
- **Framer Motion** — Animation
- **Lucide React** — Icons
- **Firebase** *(Bước 2)* — Backend

## 🚀 Chạy dự án

```bash
npm install
npm run dev
```

Mở [http://localhost:3000](http://localhost:3000) trên trình duyệt.

## 📁 Cấu trúc thư mục

```
/app             → Next.js App Router pages & layout
/components      → Reusable UI components (Navbar, Footer...)
/sections        → Page sections (Hero, About, Features...)
/lib             → Constants, utilities, types
/public/images   → Hình ảnh sản phẩm
/public/textures → Texture files
```
